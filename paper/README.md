# Paper — FEATHER

**Working title:** *FEATHER: Fisher-Eigenvalue Adaptive Thresholding for Error-Robust
Drift Detection*

This folder holds everything for the research paper (and the Review-I literature
review article, which is an early spin-off of Sections 1–2).

## Planned layout

```
paper/
├── README.md            ← this file
├── literature-review.md ← Review-I literature review article
├── main.tex             ← paper draft (LaTeX, self-contained preamble)
├── references.bib       ← verified references only (see rules.md §7)
└── figures/             ← generated by src/experiments/review1_figures.py — never hand-made data plots
```

## Compiling

No LaTeX toolchain is installed locally. Upload `main.tex`, `references.bib`,
and `figures/` to [Overleaf](https://overleaf.com) (or install MiKTeX/TeX Live)
and compile with pdfLaTeX + BibTeX. The paper uses the standard IEEE
conference format (`IEEEtran` class, `IEEEtranN` bibliography style — both
ship with TeX Live and Overleaf). Red `[TODO: …]` markers show the remaining
placeholders: author names/affiliations only. All bib author lists are
verified against the publisher pages (2026-07-16).

## Target structure (from planning notes)

1. Introduction — harmful vs benign drift, label-free monitoring gap
2. Related Work — statistical detectors (ADWIN/DDM/KSWIN), PU-index, label-free
   performance estimation, Fisher information in NNs (KFAC, pruning, EWC)
3. Preliminaries — FIM, null subspace, activation shift Δμ
4. FEATHER — the sₜ statistic; Theorem 2 (main), Lemma 1 (support)
5. FEATHER-Lite — cascaded detection
6. Experiments — Proofs A/B/C/F/G: separation, Fisher-vs-PCA ablation, cascade
   comparison, runtime, KFAC validity; datasets: synthetic 2D, Rotated MNIST,
   CIFAR-10-C
7. Limitations & Conclusion — fixed null subspace assumption, future online updates
